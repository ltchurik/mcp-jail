# Wrap every server your client already has

**Goal.** You already run six MCP servers in Claude Desktop. You want all of
them jailed by tonight, with a policy each, without retyping anything.

## One command

```sh
mcp-jail wrap --dry-run ~/Library/Application\ Support/Claude/claude_desktop_config.json
```

`--dry-run` prints the rewritten config and the policies it would write.
Satisfied?

```sh
mcp-jail wrap ~/Library/Application\ Support/Claude/claude_desktop_config.json
```

```
  wrapped  filesystem               policy /Users/me/.config/mcp-jail/policies/filesystem.yml
  wrapped  github                   policy /Users/me/.config/mcp-jail/policies/github.yml
  wrapped  fetch                    policy /Users/me/.config/mcp-jail/policies/fetch.yml
  skipped  remote-docs              remote (url) servers are not wrapped
wrote /Users/me/Library/Application Support/Claude/claude_desktop_config.json (backup: …/claude_desktop_config.json.bak)
review the policies in /Users/me/.config/mcp-jail/policies, then restart the client
```

Every stdio server's `command`/`args` becomes `mcp-jail run --policy
<policy> -- <original command>`. Remote (`url`) servers, servers already
wrapped and existing policy files are left alone (`--force` overwrites
policies). Other client files work the same way: `~/.cursor/mcp.json`,
`.mcp.json` in a Claude Code project, `--policy-dir` to put the policies
elsewhere.

## What the generated policy looks like

```yaml
# mcp-jail policy for "filesystem", generated by `mcp-jail wrap`.
# Server: npx -y @modelcontextprotocol/server-filesystem /Users/me/projects
name: filesystem

network:
  mode: none            # none | allowlist | all; allowlist is hard on Linux and macOS
  allow: []

filesystem:
  read_only: [~/.npm/_cacache]
  read_write: [/Users/me/projects, ~/.npm/_npx]   # directories from the command line are writable
  tmp: true

tools:
  default: ask
  rules:
    "read_*": allow
    "list_*": allow
    "get_*": allow
    "search_*": allow
    "delete_*": deny

lock:
  enabled: true

audit:
  path: ~/.local/state/mcp-jail/filesystem.jsonl
  args: false

sandbox:
  disabled: false
  env: [PATH, HOME, LANG, GITHUB_PERSONAL_ACCESS_TOKEN]   # the server's env keys are passed through
```

It is a starting point, not a verdict: directories named on the command line
are writable, the server's `env` keys are passed through, network is off,
unknown tools ask. `--network all` generates `mode: all` when you know a
server needs the internet and you have not listed its hosts yet.

## The afternoon after

Restart the client and use it normally. Then:

```sh
mcp-jail ui          # which servers asked for what, what was refused
mcp-jail report --since 4h
```

For each server, move the tools you saw into `allow`/`deny`, add
`args.under` for path-taking tools, replace `mode: all` with an allowlist
from the **Network** panel, and set `default: deny` once the list is stable.
Claude Desktop has no terminal, so every `ask` is a deny until you either
promote the tool or add an [approval webhook](approvals-without-a-terminal.md).
